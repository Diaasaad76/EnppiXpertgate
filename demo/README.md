# ENPPI XpertGate Demo

## Run locally
Open index.html directly (no build needed). All data is stored in-browser (localStorage).

## Demo flow (4 roles)
- **Executive Overview** - KPIs, 6 goals, 5 phases, sample 120s video + Register CTA (ROI moved to Admin).
- **Trainer Registration** - Bilingual form, automated CV scanning & specialty matching (`pdf.js` client-side), live match card (Area + Sub-discipline points), 120s video upload, instant Gate 1 score.
- **Evaluation Committee** - Login `committee` / `Enppi2026!` (password shown). All candidates on one page: video, attached CV download, Gate 1 Initiation Score highlight widget with verified CV match badge, Scanned CV Alignment Dossier (Area chips, Specialty chips, Certifications, highlighted CV excerpt), then 15-min physical assessment sheet (15 items 1-5, weights 25/20/25/15/15).
- **Approved Trainers Directory** - Search/filter, cards, CSV export.
- **Admin ROI** - Course price & ROI calculator.

## Deploy to GitHub Pages
1. Create new repo, push demo folder contents to main (root).
2. Settings > Pages > Source: main / (root) > Save.
3. Share https://<user>.github.io/<repo>/ link.
